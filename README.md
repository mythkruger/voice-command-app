# 🎙️ Voice Command App

React Native kullanılarak geliştirilen bu mobil uygulama, sesli komutları algılayıp belirli görevleri yerine getirir. Kamera ve mikrofon entegrasyonu ile birlikte çalışır.

## 🚀 Özellikler

- ✅ Wake word (uyandırma kelimesi) ile dinleme başlatma
- 📷 Kamera erişimi ve görüntü kaydı
- 🎤 Mikrofon ile sürekli ses kaydı (rolling buffer)
- 🔊 Sesli bildirimler (Text-to-Speech)
- ⬆️ Otomatik API'ye veri yükleme
- 🔁 Arka planda düzenli kayıt döngüsü
